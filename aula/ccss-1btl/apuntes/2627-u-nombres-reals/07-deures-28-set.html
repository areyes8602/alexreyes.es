7. Deures de racionalització (28 set)

Els exercicis de racionalització per al dilluns 28 de setembre, amb la solució plegada a cada apartat.

Deures per al dilluns 28 de setembre

Cada apartat té la solució plegada. Fes l'exercici a la llibreta i, quan el tinguis, clica a sobre de l'enunciat per desplegar la solució i comprovar-lo.

Els tres tipus de racionalització són a l'apartat 6.

Racionalització

1 Racionalitza les fraccions següents
a) $\dfrac{1}{\sqrt{3}}$

Tipus 1: es multiplica i es divideix per $\sqrt{3}$.

$$\frac{1}{\sqrt{3}} \cdot \frac{\sqrt{3}}{\sqrt{3}} = \frac{\sqrt{3}}{3}$$
b) $\dfrac{3}{\sqrt[4]{2^{3}}}$

Tipus 2: $3 + p = 4$, així que $p = 1$.

$$\frac{3}{\sqrt[4]{2^{3}}} \cdot \frac{\sqrt[4]{2}}{\sqrt[4]{2}} = \frac{3\sqrt[4]{2}}{\sqrt[4]{2^{4}}} = \frac{3\sqrt[4]{2}}{2}$$
c) $\dfrac{2}{\sqrt[3]{5^{2}}}$

Tipus 2: $2 + p = 3$, així que $p = 1$.

$$\frac{2}{\sqrt[3]{5^{2}}} \cdot \frac{\sqrt[3]{5}}{\sqrt[3]{5}} = \frac{2\sqrt[3]{5}}{\sqrt[3]{5^{3}}} = \frac{2\sqrt[3]{5}}{5}$$
d) $\dfrac{5}{\sqrt[7]{3^{5}}}$

Tipus 2: $5 + p = 7$, així que $p = 2$.

$$\frac{5}{\sqrt[7]{3^{5}}} \cdot \frac{\sqrt[7]{3^{2}}}{\sqrt[7]{3^{2}}} = \frac{5\sqrt[7]{3^{2}}}{\sqrt[7]{3^{7}}} = \frac{5\sqrt[7]{9}}{3}$$
2 Racionalitza les expressions següents
a) $\dfrac{2}{\sqrt{3} - \sqrt{5}}$

Tipus 3: el conjugat de $\sqrt{3} - \sqrt{5}$ és $\sqrt{3} + \sqrt{5}$.

$$\frac{2}{\sqrt{3} - \sqrt{5}} \cdot \frac{\sqrt{3} + \sqrt{5}}{\sqrt{3} + \sqrt{5}} = \frac{2(\sqrt{3} + \sqrt{5})}{(\sqrt{3})^{2} - (\sqrt{5})^{2}} = \frac{2(\sqrt{3} + \sqrt{5})}{3 - 5}$$
$$= \frac{2(\sqrt{3} + \sqrt{5})}{-2} = -\sqrt{3} - \sqrt{5}$$
b) $\dfrac{5}{3\sqrt{3} - \sqrt{2}}$

Tipus 3: el conjugat de $3\sqrt{3} - \sqrt{2}$ és $3\sqrt{3} + \sqrt{2}$.

$$\frac{5}{3\sqrt{3} - \sqrt{2}} \cdot \frac{3\sqrt{3} + \sqrt{2}}{3\sqrt{3} + \sqrt{2}} = \frac{5(3\sqrt{3} + \sqrt{2})}{(3\sqrt{3})^{2} - (\sqrt{2})^{2}} = \frac{5(3\sqrt{3} + \sqrt{2})}{27 - 2}$$
$$= \frac{5(3\sqrt{3} + \sqrt{2})}{25} = \frac{3\sqrt{3} + \sqrt{2}}{5}$$

Compte: $(3\sqrt{3})^{2} = 3^{2} \cdot 3 = 27$. El $3$ de fora també s'eleva al quadrat.

c) $\dfrac{-3}{5 - 4\sqrt{2}}$

Tipus 3: el conjugat de $5 - 4\sqrt{2}$ és $5 + 4\sqrt{2}$.

$$\frac{-3}{5 - 4\sqrt{2}} \cdot \frac{5 + 4\sqrt{2}}{5 + 4\sqrt{2}} = \frac{-3(5 + 4\sqrt{2})}{5^{2} - (4\sqrt{2})^{2}} = \frac{-15 - 12\sqrt{2}}{25 - 32}$$
$$= \frac{-15 - 12\sqrt{2}}{-7} = \frac{15 + 12\sqrt{2}}{7}$$

$(4\sqrt{2})^{2} = 16 \cdot 2 = 32$, i el denominador surt negatiu: els dos signes menys s'anul·len.

d) $\dfrac{2}{\sqrt{3} + \sqrt{5} + 3}$

Amb tres termes, s'agrupen les dues arrels, $(\sqrt{3} + \sqrt{5}) + 3$, i es fa en dues passes. Primer, pel conjugat $(\sqrt{3} + \sqrt{5}) - 3$:

$$\frac{2}{(\sqrt{3} + \sqrt{5}) + 3} \cdot \frac{(\sqrt{3} + \sqrt{5}) - 3}{(\sqrt{3} + \sqrt{5}) - 3} = \frac{2(\sqrt{3} + \sqrt{5} - 3)}{(\sqrt{3} + \sqrt{5})^{2} - 3^{2}}$$
$$= \frac{2(\sqrt{3} + \sqrt{5} - 3)}{2\sqrt{15} - 1}$$

Al denominador, $(\sqrt{3} + \sqrt{5})^{2} = 3 + 2\sqrt{15} + 5$. Encara queda una arrel, així que ara pel conjugat de $2\sqrt{15} - 1$, que és $2\sqrt{15} + 1$:

$$\frac{2(\sqrt{3} + \sqrt{5} - 3)}{2\sqrt{15} - 1} \cdot \frac{2\sqrt{15} + 1}{2\sqrt{15} + 1} = \frac{2(\sqrt{3} + \sqrt{5} - 3)(2\sqrt{15} + 1)}{(2\sqrt{15})^{2} - 1^{2}}$$
$$= \frac{2(\sqrt{3} + \sqrt{5} - 3)(2\sqrt{15} + 1)}{59}$$

Es multiplica el numerador terme a terme, amb $\sqrt{45} = 3\sqrt{5}$ i $\sqrt{75} = 5\sqrt{3}$:

$$(\sqrt{3} + \sqrt{5} - 3)(2\sqrt{15} + 1) = 2\sqrt{45} + \sqrt{3} + 2\sqrt{75} + \sqrt{5} - 6\sqrt{15} - 3$$
$$= 11\sqrt{3} + 7\sqrt{5} - 6\sqrt{15} - 3$$

I queda:

$$\frac{2}{\sqrt{3} + \sqrt{5} + 3} = \frac{22\sqrt{3} + 14\sqrt{5} - 12\sqrt{15} - 6}{59}$$

Comprovació amb la calculadora: l'enunciat i el resultat donen tots dos $0{,}287\ldots$
