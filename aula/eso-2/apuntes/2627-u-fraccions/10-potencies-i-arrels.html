10. Potencias y raíces de fracciones

La potencia de una fracción, las propiedades de las potencias y la raíz de una fracción.

Potencia de una fracción

Potencia de una fracción

Elevar una fracción a $n$ es multiplicarla por sí misma $n$ veces. Se elevan el numerador y el denominador:

$$\left(\dfrac{a}{b}\right)^n = \underbrace{\dfrac{a}{b} \cdot \dfrac{a}{b} \cdots \dfrac{a}{b}}_{n} = \dfrac{a^n}{b^n}$$

Ejemplo.

$$\left(\dfrac{3}{2}\right)^4 = \dfrac{3}{2} \cdot \dfrac{3}{2} \cdot \dfrac{3}{2} \cdot \dfrac{3}{2} = \dfrac{3^4}{2^4} = \dfrac{81}{16}$$

Operaciones con potencias de fracciones

Misma base

Para multiplicar (o dividir) potencias con la misma base, se deja la base y se suman (o se restan) los exponentes.

$$\left(\dfrac{a}{b}\right)^m \cdot \left(\dfrac{a}{b}\right)^n = \left(\dfrac{a}{b}\right)^{m+n}$$
$$\left(\dfrac{a}{b}\right)^m : \left(\dfrac{a}{b}\right)^n = \left(\dfrac{a}{b}\right)^{m-n}$$

Mismo exponente

Para multiplicar (o dividir) potencias con el mismo exponente, se deja el exponente y se multiplican (o se dividen) las bases.

$$\left(\dfrac{a}{b}\right)^m \cdot \left(\dfrac{c}{d}\right)^m = \left(\dfrac{a}{b} \cdot \dfrac{c}{d}\right)^m$$
$$\left(\dfrac{a}{b}\right)^m : \left(\dfrac{c}{d}\right)^m = \left(\dfrac{a}{b} : \dfrac{c}{d}\right)^m$$

Potencia de una potencia

Se deja la base y se multiplican los exponentes.

$$\left[\left(\dfrac{a}{b}\right)^m\right]^n = \left(\dfrac{a}{b}\right)^{m \cdot n}$$

Exponente negativo

Es la inversa de la fracción, con el exponente cambiado de signo.

$$\left(\dfrac{a}{b}\right)^{-m} = \left(\dfrac{b}{a}\right)^m$$

Exponente 0

Cualquier potencia elevada a $0$ vale $1$.

$$\left(\dfrac{a}{b}\right)^0 = 1$$

Exponente 1

Cualquier potencia elevada a $1$ es ella misma.

$$\left(\dfrac{a}{b}\right)^1 = \dfrac{a}{b}$$

Ejemplos

Ejemplo 1. Damos la vuelta a $\dfrac{4}{3}$ para tener la misma base que $\dfrac{3}{4}$:

$$\left(\dfrac{3}{4}\right)^5 \cdot \left(\dfrac{4}{3}\right)^2 \cdot \left(\dfrac{1}{3}\right)^3 = \left(\dfrac{3}{4}\right)^5 \cdot \left(\dfrac{3}{4}\right)^{-2} \cdot \left(\dfrac{1}{3}\right)^3$$

Misma base: sumamos exponentes, $5 + (-2) = 3$. Y ahora las dos tienen el mismo exponente: multiplicamos las bases.

$$= \left(\dfrac{3}{4}\right)^3 \cdot \left(\dfrac{1}{3}\right)^3 = \left(\dfrac{3}{4} \cdot \dfrac{1}{3}\right)^3 = \left(\dfrac{1}{4}\right)^3 = \dfrac{1}{64}$$

Ejemplo 2. Primero el corchete, de dentro hacia fuera:

$$\left[\left(\dfrac{2}{3}\right)^7 : \left(\dfrac{2}{3}\right)^3\right]^2 : \left(\dfrac{3}{2}\right)^8 = \left[\left(\dfrac{2}{3}\right)^4\right]^2 : \left(\dfrac{3}{2}\right)^8 = \left(\dfrac{2}{3}\right)^8 : \left(\dfrac{3}{2}\right)^8$$

Mismo exponente: dividimos las bases.

$$= \left(\dfrac{2}{3} : \dfrac{3}{2}\right)^8 = \left(\dfrac{4}{9}\right)^8 = \dfrac{4^8}{9^8}$$

Otro camino: $\dfrac{3}{2} = \left(\dfrac{2}{3}\right)^{-1}$, así que dividir entre $\left(\dfrac{3}{2}\right)^8$ es multiplicar por $\left(\dfrac{2}{3}\right)^8$, y queda $\left(\dfrac{2}{3}\right)^{16}$. Es el mismo número: $\dfrac{4^8}{9^8} = \dfrac{2^{16}}{3^{16}}$.

Raíz de una fracción

Raíz

La raíz de una fracción es la raíz del numerador entre la raíz del denominador.

$$\sqrt{\dfrac{a}{b}} = \dfrac{\sqrt{a}}{\sqrt{b}}$$

Ejemplo.

$$\sqrt{\dfrac{49}{25}} = \dfrac{\sqrt{49}}{\sqrt{25}} = \dfrac{7}{5}$$
