6. Suma i resta de fraccions

Els cinc passos per sumar i restar fraccions amb denominadors diferents.

Els passos

Procediment

1. Simplificar les fraccions.

2. Calcular el MCM dels denominadors.

3. Amplificar totes les fraccions perquè tinguin $D = \text{MCM}$.

4. Sumar o restar els numeradors.

5. Simplificar el resultat.

Si les fraccions ja tenen el mateix denominador, els passos 1, 2 i 3 no calen: es va directament al pas 4.

Al pas 4 el denominador no es toca: només s'operen els numeradors.

Exemple

$$\dfrac{3}{8} - \dfrac{5}{12} + \dfrac{5}{6} - \dfrac{28}{24}$$

1. Simplifiquem el que es pugui: $\dfrac{28}{24} = \dfrac{7}{6}$.

$$\dfrac{3}{8} - \dfrac{5}{12} + \dfrac{5}{6} - \dfrac{7}{6}$$

2. MCM dels denominadors: $\text{MCM}(8, 12, 6) = 24$.

3. Amplifiquem totes les fraccions a denominador $24$.

$$\dfrac{9}{24} - \dfrac{10}{24} + \dfrac{20}{24} - \dfrac{28}{24}$$

4. Operem els numeradors: $9 - 10 + 20 - 28 = -9$.

$$\dfrac{-9}{24}$$

5. Simplifiquem dividint per $3$.

$$\dfrac{-9}{24} = -\dfrac{3}{8}$$

Aquí simplificar d'entrada no ha canviat el MCM, però acostuma a fer que els nombres amb què es treballa siguin molt més petits.
