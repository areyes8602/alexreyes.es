Sinusoidal models

What each of the four parameters of $f(x)=a\sin\big(b(x-c)\big)+d$ does, and how to read them all off a graph, which is what the exam always asks for.

The four parameters

The general form

$$f(x) = a\,\sin\big(b(x-c)\big) + d$$

Two of the parameters translate the curve and two stretch it.

ParameterName
TranslationVertical$d$Vertical shift
Horizontal$c$Phase
StretchVertical$a$Amplitude
Horizontal$b$Frequency

The period

$b$ is not the period: it is how many oscillations fit. The period follows from it:

$$T = \dfrac{2\pi}{b} \quad \text{(in radians)} \qquad\qquad T = \dfrac{360}{b} \quad \text{(in degrees)}$$

Careful with the sign of the phase

Written as $a\sin\big(b(x-c)\big)+d$, the curve shifts $c$ units to the right. If it is written $a\sin\big(b(x+c)\big)+d$ — also common — the same shift comes out with the opposite sign. Always check how the bracket is written before quoting $c$.

Reading the parameters off the graph

The maximum and the minimum already give $a$ and $d$, with nothing to solve:

$$d = \dfrac{\text{max} + \text{min}}{2} \qquad\qquad a = \dfrac{\text{max} - \text{min}}{2}$$

The line $y=d$ is the principal axis: the horizontal line the curve oscillates about. $a$ is how far it rises and falls from there, that is half the total range.

The order worth following

  1. Principal axis and amplitude, from the maximum and the minimum: these give $d$ and $a$.
  2. Period, measured between two consecutive maxima: this gives $b = \dfrac{2\pi}{T}$.
  3. Phase, by requiring the curve to pass through a known point: this gives $c$.

The phase comes last on purpose: it needs the other three.

Exercise

The problem

For the function $f(x)=a\sin\big(b(x+c)\big)+d$, the first maximum is at $(1,2)$ and the first minimum at $(5,-8)$. Find the principal axis, the amplitude, the period and the smallest positive value of $c$, and write down the function.

Principal axis and amplitude

$$d = \dfrac{2 + (-8)}{2} = -3 \qquad\qquad a = \dfrac{2-(-8)}{2} = \dfrac{10}{2} = 5$$

The principal axis is the line $y=-3$.

Period and frequency

From maximum to minimum is half an oscillation, so the period is twice that: $T = 2\cdot(5-1) = 8$.

$$b = \dfrac{2\pi}{T} = \dfrac{2\pi}{8} = \dfrac{\pi}{4}$$

The phase

We now have $f(x)=5\sin\big(\tfrac{\pi}{4}(x+c)\big)-3$. Require it to pass through the maximum $(1,2)$:

$$2 = 5\sin\!\left(\dfrac{\pi}{4}(1+c)\right) - 3 \;\Longrightarrow\; 1 = \sin\!\left(\dfrac{\pi}{4}(1+c)\right)$$

The sine equals $1$ when its argument is $\dfrac{\pi}{2}$:

$$\dfrac{\pi}{2} = \dfrac{\pi}{4}(1+c) \;\Longrightarrow\; 2 = 1+c \;\Longrightarrow\; c = 1$$

The function

$$f(x) = 5\,\sin\!\left(\dfrac{\pi}{4}(x+1)\right) - 3$$

Check: $f(1)=5\sin\!\big(\tfrac{\pi}{2}\big)-3=2$ and $f(5)=5\sin\!\big(\tfrac{3\pi}{2}\big)-3=-8$. Both points come out.

Imposing the point takes the first solution of the trigonometric equation. Since sine repeats every $2\pi$, infinitely many phases work ($c=1$, $c=9$, $c=17$…): that is why the problem asks for the smallest positive value.

With cosine instead of sine

Cosine is the same model shifted forward by a quarter period, so any sinusoidal curve can be written either way:

$$\cos\theta = \sin\!\left(\theta + \dfrac{\pi}{2}\right)$$

Only the phase changes; the amplitude, the period and the principal axis are the same. Cosine is usually shorter when the maximum falls exactly at $x=0$, because then the phase is zero.

Homework for 14 September

Exercise 3a — reading the curve

Find the equation of the curve in the form $y = a\sin\big(b(x-c)\big) + d$. From the graph we read the maximum $(1.5,\,3)$ and the minimum $(3.5,\,-5)$.

Amplitude and principal axis

The total range is $3 - (-5) = 8$, and the amplitude is half of it:

$$a = \dfrac{3-(-5)}{2} = 4 \qquad\qquad d = \dfrac{3+(-5)}{2} = -1$$

Period and frequency

From the maximum to the minimum is half a period, so $T = 2\,(3.5 - 1.5) = 4$:

$$b = \dfrac{2\pi}{T} = \dfrac{2\pi}{4} = \dfrac{\pi}{2} \ \text{rad}$$

Phase

With $y = 4\sin\big(\tfrac{\pi}{2}(x-c)\big) - 1$, make it pass through the maximum:

$$3 = 4\sin\!\left(\dfrac{\pi}{2}(1.5-c)\right) - 1 \;\Longrightarrow\; 1 = \sin\!\left(\dfrac{\pi}{2}(1.5-c)\right)$$
$$\dfrac{\pi}{2} = \dfrac{\pi}{2}(1.5-c) \;\Longrightarrow\; 1 = 1.5 - c \;\Longrightarrow\; c = 0.5$$

The function

$$y = 4\,\sin\!\left(\dfrac{\pi}{2}\left(x - \dfrac{1}{2}\right)\right) - 1$$

Exercise 5 — two sound waves

Question

If the period of a wave is $P$ seconds, its frequency in hertz is $f = \frac{1}{P}$. An electronic signal with amplitude $4$ and frequency $f = 500$ Hz has strength $S = 4\sin(bt)$ at time $t$.

a) Find $b$.  b) An identical second signal is sent with a $1$ millisecond delay: write down its equation.  c) Write down the combined strength of the two.

a) The angular frequency

From $f = \frac{1}{T}$ we get $T = \frac{1}{500}$ s, and so

$$b = \dfrac{2\pi}{T} = 2\pi f = 2\pi \cdot 500 = 1000\pi \approx 3141.6 \ \text{rad/s}$$
$$S_1(t) = 4\,\sin(1000\pi\,t)$$

b) The delayed signal

A delay of $1$ ms is $0.001 = \frac{1}{1000}$ seconds, and a delay is subtracted inside the bracket:

$$S_2(t) = 4\,\sin\!\left(1000\pi\left(t - \dfrac{1}{1000}\right)\right)$$

c) Both together

The delay is exactly half an oscillation, because $1000\pi \cdot \frac{1}{1000} = \pi$:

$$S_2(t) = 4\,\sin(1000\pi t - \pi) = -4\,\sin(1000\pi t) = -S_1(t)$$
$$S_T(t) = S_1(t) + S_2(t) = 0$$

The two signals cancel each other out. This is what noise-cancelling headphones do: they play the same wave shifted by half a period.
